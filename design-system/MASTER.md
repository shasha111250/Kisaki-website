# Kisaki 官网设计约定

采用 ui-ux-pro-max 的 Hero + Features + CTA 结构、轻量极简布局与 Vue Composition API 建议。数据集默认橙蓝色不符合现有品牌，因此保留项目粉紫色与已有角色、Logo 素材。

- 页面：官网负责介绍、下载和上手入口；VitePress 默认主题负责文档导航、目录、搜索、深色模式与代码复制。
- 色彩：浅色正文 `#292536`、次要文字 `#686172`、品牌色 `#7952b3`；深色对应 `#f1ecf6`、`#b4aabc`、`#c2a1ee`。颜色统一放在主题 CSS 语义变量中。
- 布局：内容最大宽度 1160px，移动端留白 20px，桌面留白至少 40px。卡片按 3 / 2 / 1 列自适应。
- 字体：使用系统可用的 Inter、Noto Sans SC、微软雅黑及系统无衬线回退，无外部字体请求。
- 图标：统一使用 Phosphor Vue；平台和技术标志复用现有 SVG。装饰图标隐藏于辅助技术，图片提供适当替代文本。
- 交互：链接使用真实目的地；点击区域至少 44px；键盘焦点清晰；只用颜色、阴影和边框的轻量反馈；遵循减少动态效果设置。
- 资源：首屏预留尺寸，使用压缩 WebP；非首屏图片延迟加载。官网聊天展示明确标注为示意。
- 内容：产品行为以桌面源码为准；源码版本与发布版本区分；角色包内容和平台安装包以实际 Release 为准。

验收：检查桌面与 375px 窄屏，浅色与深色，导航、搜索、文档深层 URL、代码复制、下载和角色资源入口。
