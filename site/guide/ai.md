# 配置 AI 服务

在 **设置 → AI** 中填写连接参数。Kisaki 使用 OpenAI 兼容接口，允许自定义服务地址与模型。

## 填写连接参数

| 字段 | 如何填写 | 常见错误 |
| --- | --- | --- |
| API 地址 | 服务方提供的接口基础地址；预设通常以 `/v1` 结尾 | 填成官网首页，或填入完整的 `/chat/completions` 路径 |
| API Key | 对应服务签发的有效密钥 | 使用了另一个服务的密钥，或密钥已失效 |
| 模型 | 服务方实际开放的模型标识 | 将模型展示名当作 API 模型名 |
| 翻译与语音清洗模型 | 可选，使用该服务支持的模型 | 指定了无访问权限的模型 |

应用提供 OpenAI、DeepSeek、硅基流动和 Ollama 预设。预设负责填入地址和示例模型，**不会提供 API Key，也不保证示例模型在你的服务账号下可用**。请根据服务提供方信息修改。

例如，应用的 OpenAI 预设基础地址是：

```text
https://api.openai.com/v1
```

这个例子说明基础地址格式；模型与密钥需要你自行提供。

## 保存和测试

1. 填写参数后点击 **保存**。
2. 点击 **测试连接**，等待成功或错误信息。
3. 回到桌宠发送一条短消息，确认实际对话正常。

保存状态和连接测试状态独立。修改任意参数后，旧测试结果会清空；请重新测试。连接成功也不代表模型支持所有能力，例如图片识别或工具调用。

## 使用本地服务

以应用内 Ollama 预设为例，基础地址是：

```text
http://localhost:11434/v1
```

先启动本地服务，确保模型已下载并可用，再填写实际模型标识。当前应用的配置校验要求非空 API Key；若本地服务不验证密钥，可以在确认服务允许任意值后填写一个非敏感占位值。不要借用其他服务的真实密钥。

如果服务运行在另一台机器，请替换 `localhost` 为能访问的地址，并按照服务自身要求配置鉴权。

## 图片与工具能力

- 图片输入需要支持 Vision / 多模态的模型。
- 工具调用需要当前服务与模型支持相应工具接口。
- 翻译也会连接你配置的 AI 服务，产生该服务对应的请求和费用。

具体用法见[对话与桌面操作](./conversation)和[工具与权限](./tools)。

## 连接失败时

| 错误表现 | 检查顺序 |
| --- | --- |
| 401 / 403 | Key 是否属于当前地址，是否有效，账号是否有模型权限 |
| 404 / 模型不存在 | 基础地址是否正确，模型标识是否精确匹配 |
| 429 | 额度、请求频率与服务限流，稍后重试 |
| 网络错误 / 超时 | 服务是否启动、地址能否访问、代理和防火墙设置 |
| 文字正常，图片报错 | 模型与服务是否支持多模态输入 |

仍有问题时，在 **设置 → 诊断** 查看日志。分享日志前检查私人内容，按[常见问题](./faq)中的清单提供信息。
