# 角色导入与管理

Kisaki 的角色包含外观、提示词、表情动作与语音配置。角色文件放在用户数据目录，和应用安装文件分开。

## 导入角色包

1. 从 [GitHub Releases](https://github.com/AoralsFout/Kisaki/releases) 或可信角色作者获取 `.zip` 角色包。
2. 打开 **设置 → 角色**，使用导入入口选择文件。
3. 查看导入结果，在角色列表选择角色。
4. 回到桌面确认角色外观，并发送消息验证人设。

官方资源一般以 `characters.zip` 提供，实际角色名单以该 Release 内容为准。官网仅展示 Kisaki 作为示例。

::: tip 同名角色不会覆盖
导入使用 `character.json` 中的 `id` 作为标识。同名角色会跳过，保留原有修改。如果你要创建一个新的角色变体，给它一个不同的 id。
:::

## 修改与新建

在角色管理页面选择角色，进入编辑器。按页面提供的分组修改基本信息、提示词、外观与语音，修改后点击保存。

- 立绘角色：配置姿势、服装、情绪标签，并把图片关联到这些标签。
- Live2D 角色：配置模型入口、显示缩放、偏移与动作组。
- 提示词：描述角色身份、语言习惯与性格。
- 语音：选择音色与语音模型，或设置 GPT-SoVITS 参考音频。

离开页面时出现未保存提示，可选择保存或放弃更改。保存失败后不要直接关闭，先查看错误并重试。

你也可以使用新建角色入口。手动制作文件结构的方法见[制作角色包](./character-pack)。

## 导出和备份

在角色管理中使用导出功能，将角色保存为 `.zip`。导出的包可用于备份或在另一台设备导入。

导出角色包不等于导出聊天历史和全局设置。分享前检查包内图片、音频和提示词是否适合公开，并确认相关素材的分发权限。

## 角色存储位置

| 环境 | 角色目录 |
| --- | --- |
| 开发模式 | 桌面项目根目录 `characters/` |
| Windows 安装版 | `%APPDATA%\com.kisaki.app\characters` |
| macOS 安装版 | `~/Library/Application Support/com.kisaki.app/characters` |
| Linux 安装版 | `$XDG_DATA_HOME/com.kisaki.app/characters`，默认 `~/.local/share/com.kisaki.app/characters` |

升级通常保留用户数据。卸载时是否保留数据取决于系统和安装器；重要角色请先导出备份。
