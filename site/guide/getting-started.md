# 快速开始

Kisaki 是基于 Tauri 2 与 Vue 3 的 AI 桌宠。完成 **安装应用 → 配置 AI → 导入角色**，就可以开始文字对话。语音为可选功能，可以稍后配置。

::: tip 官网与应用
这个网站用于介绍、下载和查阅文档。AI 配置、聊天与角色编辑在安装后的桌面应用内完成，官网不接收你的 API Key。
:::

## 1. 下载并安装

前往 [GitHub Releases](https://github.com/AoralsFout/Kisaki/releases)，选择一个版本，在该版本的 Assets 中下载与你的系统和处理器架构匹配的安装包。以发布页实际提供的文件为准。

| 系统 | 常见文件 | 安装方式 |
| --- | --- | --- |
| Windows | `.exe` / `.msi` | 双击安装程序，按提示完成安装 |
| macOS | `.dmg` | 打开磁盘映像，将应用拖入 Applications |
| Linux | `.deb` / `.AppImage` | 使用发行版安装器安装 deb；或授予 AppImage 执行权限后运行 |

下载同一发布页提供的 `characters.zip`，留到第 3 步使用。**应用安装包本身不内置角色**。若发布页没有对应平台安装包，可以参考[从源码运行应用](../development/app)。

## 2. 连接 AI 服务

首次启动会出现引导。点击配置 AI 的入口，或者打开 **设置 → AI**。

1. 选择服务预设，或手动填写 OpenAI 兼容的 API 地址。
2. 填入该服务的 API Key 和模型名称。模型名称以服务提供方的可用列表为准。
3. 点击 **保存**，确认出现已保存提示。
4. 点击 **测试连接**。收到连接成功提示后再开始聊天。

::: warning 保存不等于连接成功
「已保存，连接未验证」只说明配置已存入本机。网络、模型名称、密钥或服务额度有问题时，仍然无法对话。修改配置后请重新测试。
:::

具体字段和排障方法见[配置 AI 服务](./ai)。

## 3. 导入一个角色

进入 **设置 → 角色**，使用导入入口选择刚下载的 `.zip` 角色包。导入完成后，在角色列表选择你想使用的角色。

- 首次使用时，角色目录为空，显示「还没有角色」是正常状态。
- 同名角色按 `character.json` 中的 `id` 判定，导入时会跳过已有角色。
- 不必手动解压到安装目录。使用应用内导入功能即可。

更多操作见[角色导入与管理](./characters)。

## 4. 开始第一段对话

完成 AI 与角色两项配置后，回到引导点击 **开始使用**。通过角色的对话入口打开输入框，输入「你好」，按 `Enter` 发送；`Shift + Enter` 用于换行。

如果选择「稍后再说」，只是收起引导，不表示配置已完成；可以回到设置补齐缺少的项目。桌宠被隐藏时，用 `Alt + K` 唤出或隐藏。
