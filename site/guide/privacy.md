# 数据与隐私

Kisaki 是本地优先的桌面应用。角色、会话、设置与日志保存在本机；使用联网功能时，必要内容会直接发送到你配置的服务。

## 保存在本机的数据

- 设置、聊天会话与历史。
- 角色图片、模型、提示词与语音配置。
- 窗口状态和诊断日志。
- API 凭据：优先存入系统密钥链；不可用时回退到本地加密存储。

应用不包含广告、遥测或使用统计 SDK，日志不会自动上传。

## 哪些内容会离开设备

| 功能 | 外部服务收到的内容 |
| --- | --- |
| AI 对话 | 凭据、模型、人设提示词、必要历史、输入和工具结果 |
| 图片识别 | 你发送的图片或获准读取的图片 |
| 文件工具 | 获准读取的文件内容或摘要 |
| 屏幕观察 | 每次获准截取的显示器截图 |
| TTS | 凭据、待合成文本、模型和音色参数 |
| 搜索 / 天气 | 查询词、城市或时间范围及所需凭据 |
| 更新 | 请求 GitHub Releases 更新清单，并下载用户确认的更新包 |

服务可能按各自隐私政策保存请求。Kisaki 维护者不代理上述服务请求，也不会接收你的 API 凭据。

## 备份与删除

重要角色请在角色管理中导出 `.zip`。备份角色不包含会话与全局设置；请根据实际需要保留相应本地数据。卸载程序是否删除数据取决于系统和安装器。

应用内的 **清除所有本地数据** 会删除角色、会话、设置、日志、缓存备份，以及 Kisaki 创建的系统密钥链条目。执行前完成所需备份，并阅读确认提示。

## 分享日志

日志用于诊断，按大小轮转。默认不记录敏感原文，也不会自动上传。开启敏感诊断后，日志可能包含对话片段、工具参数与路径等信息。

导出和分享前检查是否含私人内容，排障后关闭不再需要的敏感诊断。

完整政策见桌面项目的[隐私说明](https://github.com/AoralsFout/Kisaki/blob/main/PRIVACY.md)。本文依据本地源码中的 `PRIVACY.md` 与设置页面编写。
