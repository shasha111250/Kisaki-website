# 语音与语言

语音合成是可选项。不开启语音也能正常进行文字对话。全局引擎在 **设置 → 语音** 中配置，角色音色在 **设置 → 角色 → 语音** 中配置。

## 选择语音引擎

| 引擎 | 需要准备 | 使用方式 |
| --- | --- | --- |
| 不使用 | 无 | 仅显示文字回复 |
| CosyVoice | 阿里云百炼 DashScope Key、可用音色 | 连接云端语音服务 |
| GPT-SoVITS | 已启动的本地服务、参考音频 | 连接配置的 HTTP 服务 |

选择引擎后，开启 **启用语音播报**。需要保存的参数修改后点击保存，检查成功提示。

## 配置 CosyVoice

1. 在语音设置中选择 CosyVoice，填入自己的百炼 API Key。
2. 选择模型与服务地域。应用源码默认模型为 `cosyvoice-v3-flash`，可用选项以当前应用和服务账号为准。
3. 使用新加坡地域时，还需要填写 `WorkspaceId`；Key、工作空间和音色应对应同一服务环境。
4. 保存配置，使用音色列表获取功能确认能访问你的音色。
5. 在角色语音编辑器选择音色 ID 与匹配的语音模型，保存角色。
6. 发送一条短消息，验证是否听到语音。

::: tip 角色音色不是通用凭据
其他角色包中的音色 ID 不一定对你的账号可用。角色已导入但没有声音时，先改用你自己有权限的音色。
:::

没有 API Key、角色没有音色 ID，或新加坡地域缺少 WorkspaceId 时，应用会提示语音配置尚未就绪。

## 配置 GPT-SoVITS

1. 先按你使用的 GPT-SoVITS 项目文档启动兼容服务。
2. 在语音设置中选择 GPT-SoVITS，填写 API 地址。应用默认值为 `http://127.0.0.1:9880`。
3. 保存连接配置。
4. 打开当前角色的语音编辑器，选择参考音频，填写音频转录文本及其语言。
5. 保存角色，发送短消息测试。

参考音频必须能被实际运行的语音服务访问。服务在其他机器上时，Kisaki 本机的文件路径未必有效。高级采样和速度参数建议先保留默认值，确认链路正常后再调节。

## 分清三种语言

| 设置 | 影响范围 |
| --- | --- |
| 设置 → 通用 → 界面语言 | 菜单、按钮与提示文案 |
| 设置 → 语音 → 显示语言 | AI 回复的翻译显示语言 |
| 角色的语音语言 | TTS 合成使用的角色语言 |

例如，可以使用中文界面、中文显示回复，同时让角色以日文语音回应。翻译需要可用的 AI 服务；所选音色也必须支持目标语言。

## 回复有文字但没有声音

依次检查总开关、引擎选择、系统音量、服务连接、角色音色或参考音频。CosyVoice 还需检查账号权限、地域与模型是否匹配；GPT-SoVITS 需检查服务日志和音频路径。更多方法见[常见问题](./faq)。
